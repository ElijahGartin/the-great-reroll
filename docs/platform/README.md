# Platform Contract Sync

This directory contains the app-local copy of the platform contract and agent
checklist.

Recommended source files from `platform-core`:

- `docs/contracts/managed-application-contract.md`
- `docs/contracts/agent-review-checklist.md`
- `docs/contracts/managed-application-contract.schema.yaml`
- `docs/contracts/managed-application-onboarding.md`

Keep these copied files aligned with the matching source files in
`platform-core`, and keep the copied contract version aligned with
`.platform/application.yaml`.
