# The Great Reroll

World of Warcraft: Forever race/class draft and character name generator.

## Run locally
Open `index.html` in any modern browser.

## GitHub Pages
1. Upload the latest app file as `index.html` in the repository root.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then save.

> The current app is intentionally a single-file HTML build with artwork embedded directly in the file.
